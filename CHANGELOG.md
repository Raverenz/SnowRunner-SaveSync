# Changelog

## 1.0 — first public release

- Player manager for host/player unlock sync, manual upgrade editing, money and XP/rank editing.
- Upward-only XP sync; author-confirmed in-game XP/rank behavior on 2026-11-19.
- Expandable fleet/parts browser, STS locations and nominal company valuation with explicit incomplete-data warnings.
- Host ZIP input and a separate host-only packer with automatic profile/slot discovery.
- English default plus Polish, German, French, Spanish and Portuguese in both tools.
- Offline cats and rarity effects.
- Public-source preparation, Windows CI, release packaging, checksums and draft-release provenance workflow.

This is version 1.0. The maintainer has chosen to include the catalog snapshots; see the third-party data notices.
